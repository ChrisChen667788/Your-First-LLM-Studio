# v3.2.0-v3.3.4 Remediation Execution and Operational Acceptance

Date: 2026-08-30

## Decision boundary

This 15-version train turns the seven source-owned remediation gaps from
v3.0-v3.1 into deterministic execution contracts, then projects the result into
operational acceptance. It does not execute remote production mutations, create
third-party credentials, sign on behalf of an organization, approve a release,
or authorize production.

The active product source version remains `v1.5.1`. These versions are source
and evidence milestones. Distribution remains `HOLD`; production remains
`BLOCKED` until the required external records verify.

## Acceptance

Repository acceptance requires typed contracts, deterministic digests, unit
tests, route ownership, full route smoke, production build, source hygiene,
security preflight, live API export, and browser verification. External
acceptance remains missing until independently operated records satisfy the
existing signature, pinned-key, freshness, predecessor, coverage, reviewer,
and immutable-retention checks.
