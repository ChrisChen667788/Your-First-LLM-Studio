# v2.6.0-v2.7.4 Governed Autonomy and Interoperability Plan

Date: 2026-08-29

## Scope and truth boundary

This independently bounded 15-version train follows the v2.5.4 deployment
lifecycle closure. It turns existing feature-owned evidence into two read-only,
fail-closed projections:

- `v2.6.0-v2.6.9` covers governed model choice, provider routing, grounded
  context, tool permissions, protected actions, workflow replay, benchmark
  quality, adapter rollback, audit provenance, and independent review.
- `v2.7.0-v2.7.4` covers OpenAI-compatible clients, MCP extensions, portable
  model artifacts, workspace/identity portability, and independent closure.

`sourceStatus: pass` means the verifier, API, UI, tests, exporter, and roadmap
contracts exist. `localStatus: pass | attention` reflects current source-owned
signals. `externalStatus: hold` and `productionStatus: blocked` remain invariant
until all independently signed records verify. No endpoint creates, signs, or
approves those external records.

## Architecture

- `governed-autonomy-source-signals.ts` owns the exception-safe normalized
  projection over existing Runtime, Provider, Retrieval, Agent, Workflow,
  Fine-tune, Extension, MCP, Model Supply Chain, and Governance read models.
- `source-backed-assurance-projection.ts` attaches source signals to the shared
  strict external chain without weakening signature, key pin, freshness,
  predecessor, semantic, or independent-review checks.
- `governed-autonomy-readiness-train.ts` and
  `open-ecosystem-interoperability-train.ts` own version definitions and env
  prefixes. Their routes remain thin GET wrappers.
- `/experiments` extends the existing segmented operational assurance panel;
  no duplicate admin-only shell or mutation endpoint is introduced.

## APIs and external records

- `GET /api/experiments/governed-autonomy-readiness`
- `GET /api/experiments/open-ecosystem-interoperability`

External records use the existing four-file contract:

```text
FIRST_LLM_GOVERNED_AUTONOMY_<KEY>_{PATH,SIGNATURE_PATH,PUBLIC_KEY_PATH,KEY_SHA256}
FIRST_LLM_OPEN_ECOSYSTEM_<KEY>_{PATH,SIGNATURE_PATH,PUBLIC_KEY_PATH,KEY_SHA256}
```

The first v2.6 record must bind verified v2.5.4. The first v2.7 record must bind
verified v2.6.9. Final reviewers must be independent from all reviewed control
issuers.
