# v2.0.3–v2.0.5 Production Lifecycle Closure — implementation plan

Date: 2026-08-22
Status: all remaining bounded v2.0.x source contracts implemented; production execution remains external.

## v2.0.3 External Transition Witness

Reads a separately signed transition witness through
`FIRST_LLM_TRANSITION_WITNESS_*`. The witness must use a distinct pinned key, bind an
approved v2.0.0 decision digest, name a different durable issuer, and assert external
production outcome, multi-region failover, target isolation, and post-deploy health.

## v2.0.4 Independent Rollback Witness

Reads `FIRST_LLM_ROLLBACK_WITNESS_*` and requires a separate authority, exact
transition digest, immutable rollback-plan digest, passed rehearsal, non-negative RPO,
and positive RTO. A local rehearsal cannot replace this external artifact.

## v2.0.5 Release Closure Archive

Reads `FIRST_LLM_RELEASE_CLOSURE_ARCHIVE_*` with a third trust anchor. The archive
must be fresh, independently issued, and bind the approved decision, transition, and
rollback digests exactly. It is a terminal evidence record, not a production-state
transition.

## Invariant

Every stage is read-only and retains `productionStatus: "blocked"`. Neither an
individual verified artifact nor a complete three-stage chain provides a signing key,
deployment action, or local authorization capability.
