# v1.10.2–v1.12.0 Executable Development Plan

Date: 2026-08-21

## Delivery rule

This plan closes repository-owned contracts, route ownership, durable evidence,
and local acceptance hooks for the ten versions after `v1.10.1`. A source-contract
pass never changes the active `1.5.1` release truth and never substitutes for a
managed service, a real remote artifact, Apple distribution, an independent
security/HA test, or organization approval. Those conditions remain `HOLD`.

## Aggregate delivery contract

The repository provides a single read model at
`/api/experiments/v1102-v1200-source-train`, a recordable durable receipt, and
an `/experiments` panel. The projection must always report ten source contracts,
must never set an external or production version to `PASS`, and must show the
specific local gap and external blocker for each version.

Evidence command: `npm run evidence:v1102-v1200-source-train`.
