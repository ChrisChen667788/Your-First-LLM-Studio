# v2.0.2 Release Authority Decision Ledger — implementation plan

Date: 2026-08-22
Status: source-owned external decision projection implemented; production authorization remains external.

## Objective

`v2.0.2` closes the representation gap after evidence verification. It reads a
separately signed decision from the independent release authority, validates a second
pinned trust anchor, and binds the decision to the exact verified v2.0.0 evidence
bundle and rollback plan. The local studio records no decision and performs no
deployment transition.

## Delivered repository-owned slice

- Decision, detached signature, public key, and pinned key digest are read only from
  `FIRST_LLM_RELEASE_DECISION_*` configuration paths.
- The decision must bind the verified evidence bundle digest, v2.0.0, durable issuer,
  fresh timestamps, and an immutable rollback-plan digest.
- The decision signer must belong to a durable organization different from the
  evidence-bundle issuer; local/test/fixture identities fail closed.
- Valid rejections are surfaced as `rejected`; valid approvals are surfaced as
  `approved`. Neither state changes `authorizationStatus: not-authorized` or
  `productionStatus: blocked` in this repository.

## External release authority inputs

The release authority owns the real decision record, signer, semantic evidence review,
deployment-control transition, and emergency rollback execution. This project only
projects a verified decision for operators to inspect alongside evidence state.
