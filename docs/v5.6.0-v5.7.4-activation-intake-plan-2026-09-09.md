## Scope and Findings

The v5.4-v5.5 observation and decision validators check shape, metadata digests,
and fingerprint equality. They do not verify a detached signature with a public
key. Their local fixtures do not establish external signature validity. This
train adds an actual Ed25519 verifier and an authenticated operator import path.

## Ownership

`features/evidence/activation-intake/` owns contracts, trust loading, signing
bytes, verification, transactional reducers, durable storage, read models and
the application handler. The API route delegates to that handler. The inbox
is composed inside the existing Experiments activation panel.

The dedicated ledger retains detached signatures and signed digest-only
envelopes so records can be cryptographically reverified after restart/export.
It contains no private keys, tokens, raw model output or archive payloads.
This is a deliberate change from the preceding metadata-only ledger, which
remains separately readable and cannot confer cryptographic eligibility.
