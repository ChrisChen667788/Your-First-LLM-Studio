# v5.0.0-v5.1.4 External Evidence Handoff Plan

Date: 2026-09-08

## Purpose

The preceding authority-campaign train can model profiles, campaigns,
assignments, challenges, and receipt envelopes. This train provides the strict
handoff boundary that a controlled external system would need to execute that
work: handoffs contain digests rather than evidence payloads or credentials,
authority/archive witnesses are short-lived, observer delivery and receipt
verification are per-domain, discrepancies are durable, and an independent
decision remains separate from local release state.

No source feature, durable store, injected adapter, fixture, or export may claim
that a credential resolver, issuer, archive, observer, distribution authority,
or production control plane is actually controlled or approved.

## Fifteen-Version Scope

| Version | Milestone | Source-owned boundary |
| --- | --- | --- |
| `v5.0.0` | External Handoff Request Contract | Bind one fourteen-domain, digest-only request to a profile, campaign, escrow digest, requester, and short expiry. |
| `v5.0.1` | Credential Resolution Witness | Represent a resolution result as a short-lived signed digest record, never a secret value. |
| `v5.0.2` | Trust Discovery Witness | Bind discovery evidence to the exact handoff, profile, issuer, signer, and validity window. |
| `v5.0.3` | Rotation Continuity Witness | Make key-rotation continuity explicit rather than silently replacing a signer. |
| `v5.0.4` | Immutable Archive Read-back Witness | Bind archive policy/object digests and a bounded read-back window without claiming storage enforcement. |
| `v5.0.5` | Independent Observer Delivery | Require one assignment digest and acknowledgment or decline per source domain. |
| `v5.0.6` | Authority Dispatch Receipt | Keep a digest-bound dispatch acknowledgment without retaining endpoint payloads. |
| `v5.0.7` | Signed Receipt Verification | Bind external receipt, signer, signature, outcome, and source domain to the current handoff. |
| `v5.0.8` | Receipt Reverification Window | Exclude evidence after the handoff window expires. |
| `v5.0.9` | Discrepancy Case Ledger | Preserve missing, mismatched, stale, and rejected cases until a terminal resolution. |
| `v5.1.0` | Fourteen-Domain Coverage Projection | Require acknowledged observer, accepted dispatch, verified receipt, and no open discrepancy per domain. |
| `v5.1.1` | External Evidence Renewal Queue | Surface expired evidence as held work rather than silently carrying it forward. |
| `v5.1.2` | Distribution Decision Request | Bind a short-lived request to an exact coverage digest. |
| `v5.1.3` | Independent Decision Envelope | Validate a decision envelope against the exact request without changing local release authority. |
| `v5.1.4` | Production Safety Interlock | Retain an explicit non-authorizing production projection for every handoff state. |

## Source Contracts

- `features/evidence/external-handoff.ts` owns strict handoff, witness,
  delivery, verification, discrepancy, decision, coverage, store-reducer, and
  default fail-closed port contracts.
- `features/evidence/external-handoff-store.ts` persists bounded,
  idempotent, digest-bound handoffs and observations without secret material or
  external evidence payloads.
- `/api/experiments/evidence-external-handoff-train` exposes a feature-owned
  read model and source-gate receipt behind the existing trusted-operator
  boundary.
- `/experiments` renders handoffs and coverage as a separate panel rather than
  moving external-evidence state into Agent or Admin shells.

## Source Acceptance

1. Reject raw secrets, incomplete source coverage, profile/campaign mismatch,
   stale or malformed witnesses, mismatched observer/dispatch/verification
   bindings, invalid discrepancy state, and decision-envelope drift.
2. Preserve idempotency for a handoff and avoid eviction of evidence when
   bounded capacity is reached.
3. Keep every external port unavailable by default; injected ports must return
   outputs bound to the exact active handoff.
4. Keep external `HOLD` and production `BLOCKED` even if an isolated test port
   returns complete, approved fixtures.

## External Evidence Still Required

1. a controlled credential resolver, authority discovery service, rotation
   evidence, and immutable archive read-back;
2. fourteen independently acknowledged observer workloads and current signed
   verification receipts;
3. authority-owned discrepancy resolution and a separately controlled
   distribution decision; and
4. a production control-plane transition with an independent execution witness.
