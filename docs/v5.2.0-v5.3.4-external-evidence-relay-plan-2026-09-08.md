# v5.2.0-v5.3.4 External Evidence Relay Plan

Date: 2026-09-08
Status: source-complete, external evidence needed
Surface: `/experiments` and `/api/experiments/evidence-external-relay-train`

## Purpose

This fifteen-version train adds a controlled, digest-only relay boundary after the
`v5.0.0-v5.1.4` external handoff contract. It is deliberately not a production
activation path. Its job is to make later authority integration reviewable:

- a relay descriptor pins an authority, HTTPS destinations, opaque credential
  reference digest, and trust-anchor fingerprint;
- a one-shot resolver may provide an authorization value only in memory for one
  request; no raw secret is stored in the relay store, train receipt, export, or
  UI state;
- requests and receipts are strict, bounded, expiry-aware, and bound to exact
  configuration, handoff, operation, endpoint, and signer digests;
- malformed, stale, duplicate, mismatched, and failed imports are retained only
  as bounded digest-only quarantine records;
- fourteen source domains are reconciled from current accepted verification
  receipts, while any stale receipt or quarantine keeps the result on hold;
- no local descriptor, transport, receipt, reconciliation, or decision-shaped
  response can authorize distribution or production.

## Safety Invariants

1. The default relay transport always throws `external-unavailable`.
2. A real HTTP transport can be constructed only by injecting a credential
   resolver and, for tests, an HTTP client.
3. Resolver output must match the configuration's opaque reference digest and
   have a future expiry; it is not included in any durable model.
4. URLs are HTTPS-only and reject embedded credentials, non-default ports,
   localhost, private IPv4, and local IPv6 address forms.
5. Relay requests are capped at 64 KiB and responses at 128 KiB; redirects are
   denied and timeouts must be between one and thirty seconds.
6. A receipt must bind exact request, configuration, handoff, operation,
   milestone shape, endpoint digest, trust-anchor fingerprint, and receipt
   digest.
7. Quarantines prevent a 14-domain reconciliation from becoming ready.
8. A ready reconciliation is still not a distribution decision or production
   authorization.

## Evidence and Promotion State

The source gate proves repository-owned behavior only. It must not be read as
evidence that a real authority, credential resolver, archive, observer,
distribution signer, or production transition exists. Until independently
issued receipts are configured and verified, external readiness remains `HOLD`
and production remains `BLOCKED`.
