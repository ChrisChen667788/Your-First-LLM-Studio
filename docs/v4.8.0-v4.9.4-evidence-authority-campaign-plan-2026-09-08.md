# v4.8.0-v4.9.4 Evidence Authority Campaign Plan

Date: 2026-09-08

## Purpose

The preceding acceptance-lifecycle train makes external authority a strict
boundary. This train makes the remaining evidence request operational without
inventing that authority: profiles retain opaque credential references only,
campaigns cover the fourteen source milestones exactly once, independent
observer assignments and nonce-bound challenges are explicit, and receipts are
quarantined until their profile, campaign, challenge, signer, freshness, and
digest links all match.

No source feature, local store, injected port, fixture, or export may claim a
controlled identity provider, KMS/HSM, immutable archive, independent observer,
distribution decision, or production authorization.

## Fifteen-Version Scope

| Version | Milestone | Source-owned boundary |
| --- | --- | --- |
| `v4.8.0` | Authority Profile Registry | Register one digest-bound authority profile with distinct external HTTPS endpoints. |
| `v4.8.1` | Credential Reference Boundary | Permit only opaque vault, workload-identity, or operator-approved references. |
| `v4.8.2` | Trust Discovery Snapshot | Bind a fresh issuer, JWKS, and archive-policy snapshot to a profile. |
| `v4.8.3` | Key Rotation Observation | Make trust-key changes visible as a new snapshot instead of silent replacement. |
| `v4.8.4` | Archive Retention Policy | Require a retention-policy digest rather than a local path or mutable note. |
| `v4.8.5` | Fourteen-Domain Campaign Manifest | Cover all source milestones exactly once under a bounded campaign window. |
| `v4.8.6` | Independent Observer Assignment | Require a distinct observer, campaign, and milestone lineage. |
| `v4.8.7` | Challenge Nonce Lifecycle | Bind one profile, campaign, package, milestone, nonce digest, and expiry. |
| `v4.8.8` | External Dispatch Binding | Require discovery and dispatch to echo current profile and challenge digests. |
| `v4.8.9` | Receipt Envelope Intake | Require strict, fresh, signer-bound envelopes tied to issued challenges. |
| `v4.9.0` | Receipt Quarantine and Reconciliation | Quarantine malformed, stale, mismatched, or rejected receipts with a reason. |
| `v4.9.1` | Receipt Freshness Renewal | Measure evidence age from profile policy and exclude stale coverage. |
| `v4.9.2` | Escrow Coverage Bundle | Count a domain only when its assignment and accepted-for-binding receipt both exist. |
| `v4.9.3` | Distribution Request Readiness | Export coverage gaps without locally granting distribution. |
| `v4.9.4` | Production Authority Separation | Preserve an explicit blocked production projection regardless of campaign state. |

## Source Contracts

- `features/evidence/authority-campaign.ts` owns strict schemas, validators,
  campaign/receipt reducers, quarantine classification, escrow projection, and
  the default fail-closed external port.
- `features/evidence/authority-campaign-store.ts` persists only bounded,
  digest-bound profiles, campaigns, assignments, and receipt dispositions.
- `/api/experiments/evidence-authority-campaign-train` exposes a read model and
  source-gate receipt protected by the existing trusted-operator boundary.
- `/experiments` renders the feature-owned campaign read model without moving
  this state back into Admin or Agent shells.

## Source Acceptance

1. Reject raw credential values, local HTTP endpoints, duplicate endpoints,
   stale trust snapshots, incomplete campaigns, self-observer assignments, and
   malformed or stale receipt envelopes.
2. Preserve idempotency for profiles and campaigns; do not silently replace a
   digest bound to an existing identifier.
3. Keep every external port unavailable by default and require exact discovery,
   dispatch, challenge, and receipt binding from any injected adapter.
4. Keep distribution `HOLD` and production `BLOCKED` until separately supplied
   external records meet the existing acceptance lifecycle policy.

## External Evidence Still Required

1. a controlled issuer, key-rotation service, and credential resolver;
2. immutable archive read-back with retention and legal-hold enforcement;
3. fourteen current, independently observed and externally attested receipts;
4. independent discrepancy resolution, distribution approval, and production
   authority.
