## Fail-closed invariant

The state builder returns `productionStatus: "blocked"` and `externalStatus: "hold"`
for every input combination. The all-passing unit fixture verifies that local candidate,
desktop, security, release bundle, and external-readiness data cannot turn the state
to ready. The API only snapshots this local reconciliation and cannot import, mint,
or authorize independent production receipts.

## Remaining production gates

Managed identity/data/telemetry, independent desktop distribution, cross-region
failover, billing settlement, security assessment, and organization sign-off remain
externally controlled. Their real receipts, validation process, and final authorization
are intentionally not synthesized or claimed by this repository.
