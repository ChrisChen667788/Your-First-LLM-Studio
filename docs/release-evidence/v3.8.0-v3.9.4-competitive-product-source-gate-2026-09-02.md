## Implemented source

- The official-source registry pins 18 first-party product and model sources,
  freezes changed claims for review, and enforces a 14-day freshness window.
- Provider capability discovery checks account-visible model catalogs before
  inference. Workload routing stays fail-closed until each candidate has at
  least 20 aligned quality samples and compatible capability evidence.
- Agent contracts cover protected tools, approval, resume, cancellation,
  idempotency, branching, usage attribution, cache attribution, isolated team
  plans, and pre-execution sandbox policy.
- Multimodal admission binds model capability, transport support, official
  documentation, licensed task assets, and evaluator compatibility.
- Model Hub operations unify acquisition, transfer, checksum/provenance,
  migration, load, hot switch, unload, serve, and inspection contracts. Local
  Server diagnostics expose multi-instance configuration, concurrency, TTL,
  request ledgers, auth, cancellation, latency, and token accounting.
- RAG contracts cover connector and index revisions, parser/index pinning,
  deletion propagation, rollback, paired quality runs, citation and answer
  checks, leakage checks, freshness, and human feedback.
- Fine-tune federation exposes MLX-LM, LLaMA-Factory, ModelScope SWIFT, and
  Transformers/PEFT capabilities without marking preview plans executable.
- Team Studio admission binds workspace role, publisher identity, signatures,
  review, revocation, rollback, and optimistic revisions.
- `/experiments` presents source, local, external, and production truth as
  separate states; no lower gate can promote an external or production claim.
