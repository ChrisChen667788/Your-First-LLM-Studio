## Decision

All fifteen repository-owned authority-campaign contracts are source-complete.
The train provides non-local HTTPS authority profiles, opaque credential
references, trust/rotation/retention snapshots, complete fourteen-domain
campaigns, independent observer assignments, nonce-bound challenges, strict
receipt envelopes, quarantine, freshness, escrow coverage, and explicit
authority separation.

This is a source-completion decision, not an authority or release decision. The
current projection is source `15/15` pass, deterministic local `9/15` pass,
registered profiles `0`, persisted campaigns `0`, accepted-for-binding receipts
`0`, covered milestones `0/14`, external `HOLD`, and production `BLOCKED`.

## Implemented Scope

- `features/evidence/authority-campaign.ts` owns strict profile, credential
  reference, trust snapshot, campaign, assignment, challenge, receipt,
  quarantine, escrow, and external-port contracts;
- raw credential values, loopback/private endpoints, duplicate endpoint roles,
  stale snapshots, incomplete campaigns, self-observer assignments, stale
  envelopes, and mismatched digest bindings are rejected by default;
- `features/evidence/authority-campaign-store.ts` persists bounded,
  idempotent, digest-bound profile/campaign/assignment/receipt state without
  storing secret material;
- a feature-owned Experiments API, panel, deterministic export, release-train
  milestones, route-smoke checks, and CI route coverage make the source train
  observable without reconnecting it to Admin or Agent shells.

## Remaining External Evidence

The following are intentionally not represented as completed by source code:

1. a controlled credential resolver plus current issuer and key-rotation
   authority;
2. live trust discovery and immutable archive read-back with retention and
   legal-hold enforcement;
3. fourteen independently executed observer assignments and current externally
   attested receipt envelopes; and
4. discrepancy resolution, distribution approval, and production authority.

An injected test port, local profile, source receipt, quarantine record, or
escrow manifest cannot replace those external records.
