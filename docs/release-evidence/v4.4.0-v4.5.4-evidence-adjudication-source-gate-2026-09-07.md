# v4.4.0-v4.5.4 Evidence Adjudication Source Gate

Date: 2026-09-07

## Decision

All fifteen repository-owned adjudication and retention contracts are
source-complete. The train makes a candidate receipt reviewable only when it
is bound to strict reviewer identity metadata, distinct roles, artifact
read-back metadata, a domain metric policy, and a re-observation reference.
Portable exports remain digest-only, and revocation retains lineage while
blocking a package from aggregate promotion.

This is a source-completion decision, not an external acceptance decision. The
current projection is source `15/15` pass, deterministic local `7/15` pass,
accepted workload packages `0/14`, external verification `0`, distribution
`HOLD`, and production `BLOCKED`.

## Implemented Scope

- `features/evidence/adjudication.ts` owns fifteen exact contracts from
  reviewer attestation through the aggregate promotion gate;
- strict reject-by-default parsing for stale or placeholder reviewer and
  read-back metadata, incomplete policy metrics, self-review, and unknown
  threshold changes;
- an injected external verifier/read-back port; its default implementation is
  deliberately unconfigured and cannot convert a local fixture into external
  authority;
- an Experiments read model, API route, panel, deterministic export script,
  release-train entries, and cross-surface route-smoke coverage;
- a bounded test runner concurrency policy for the real Python evaluator and
  collection lifecycle probes, so host contention cannot turn valid execution
  into a false negative.

## Remaining External Evidence

The following are intentionally not represented as completed by source code:

1. a trusted organization issuer/key verifier and reviewer-principal mapping;
2. immutable archive read-back with retention/legal-hold enforcement;
3. current accepted packages for all fourteen domain milestones, including
   independently executed re-observations; and
4. independent threshold ownership, distribution approval, and production
   authority.

Local fixtures, dependency-injected ports, source receipts, and export
manifests are not substitutes for those external records.
