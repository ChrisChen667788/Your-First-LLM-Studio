## Decision

All fifteen repository-owned external-evidence handoff contracts are
source-complete. The train provides a strict digest-only handoff, authority and
archive witness contracts, per-domain observer delivery, authority dispatch,
signed receipt verification, discrepancy cases, coverage projection, renewal,
decision request/envelope binding, and production safety interlock.

This is a source-completion decision, not a credential, authority, distribution,
or production decision. The current projection is source `15/15` pass,
deterministic local `9/15` pass, persisted handoffs `0`, authority witnesses
`0`, observer receipts `0`, verified receipts `0`, decision envelopes `0`,
covered milestones `0/14`, external `HOLD`, and production `BLOCKED`.

## Implemented Scope

- `features/evidence/external-handoff.ts` owns strict handoff, authority
  witness, observer delivery, dispatch, verification, discrepancy, decision,
  coverage, durable-state reducer, and default fail-closed external-port
  contracts;
- `features/evidence/external-handoff-store.ts` persists bounded, idempotent,
  digest-bound state without raw credentials or external evidence payloads;
- a feature-owned Experiments API, panel, deterministic export, release-train
  milestones, route-smoke checks, CI route coverage, and documentation expose
  source readiness without reconnecting the state to Admin or Agent shells.

## Remaining External Evidence

The following are intentionally not represented as completed by source code:

1. a controlled credential resolver and live authority trust/rotation service;
2. immutable archive read-back with verified retention and legal-hold behavior;
3. fourteen current independently acknowledged workloads and signed authority
   verification receipts;
4. externally controlled discrepancy resolution and distribution decision; and
5. a separate production control-plane transition with an independent execution
   witness.

An injected test port, local handoff, witness fixture, coverage projection, or
decision envelope cannot replace those external records or authorize production.
