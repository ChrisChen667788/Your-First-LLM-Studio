## Runtime Stability Closure

Opening `/experiments` initially exposed a runtime-data placement defect: `.env.local` pointed `LOCAL_AGENT_DATA_DIR` into the iCloud-backed repository, where historical JSON files still carried the macOS `compressed,dataless` flag. Concurrent panel reads could block the Node process in a synchronous filesystem read even though isolated route smoke passed.

Runtime state now points to the entity-backed application-support directory at `~/Library/Application Support/local-agent-lab/observability`. The real PostgreSQL receipt was migrated there, v1.5 evidence was regenerated against the same store, and the live page loaded v1.4 at 15/15 plus v1.5 at 14/14 and 1/1 with no browser console errors.

The move also exercised an older Admin compatibility archive that predated its durable schema version. A locked atomic migration preserved all 116 archived historical hits, retained the legacy payload as a backup, and made the GA evidence API succeed on the first read. That aggregate API is now part of the cross-surface route smoke contract.
