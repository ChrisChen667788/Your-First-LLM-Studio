## Non-promotion invariant

An external `approved` decision is only a verified read-model projection. The service
has no write endpoint, signing capability, release action, or production-state update;
its output stays `authorizationStatus: "not-authorized"` and
`productionStatus: "blocked"` for every input.

## Remaining external action

The independent release authority must execute its own approved transition and retain
the actual control-plane and rollback records. The local studio neither performs nor
claims that operation.
