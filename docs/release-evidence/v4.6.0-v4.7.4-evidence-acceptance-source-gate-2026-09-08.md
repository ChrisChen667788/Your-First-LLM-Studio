# v4.6.0-v4.7.4 Evidence Acceptance Lifecycle Source Gate

Date: 2026-09-08

## Decision

All fifteen repository-owned evidence-acceptance lifecycle contracts are
source-complete. The train provides strict authority configuration, durable
acceptance-package intake, fenced state transitions, distinct re-observation,
challenge binding, revocation, portable import, evidence-aging projection, and
a distribution-handoff gate.

This is a source-completion decision, not an external acceptance decision. The
current projection is source `15/15` pass, deterministic local `8/15` pass,
externally verified packages `0/14`, external verification `HOLD`, and
production `BLOCKED`.

## Implemented Scope

- `features/evidence/acceptance-lifecycle.ts` owns the fifteen exact contracts
  from authority configuration through distribution handoff;
- strict reject-by-default parsing for malformed authority configuration,
  placeholder identities, non-HTTPS endpoints, stale re-observations,
  digest mismatches, illegal state transitions, and stale writers;
- an injected external verification port whose default implementation is
  deliberately unavailable and cannot turn a local fixture into authority;
- durable, idempotent acceptance-package persistence with append-only events,
  revision fencing, revocation, and bounded digest-only portable manifests;
- an Experiments read model, API, panel, deterministic export script,
  release-train milestones, and cross-surface route-smoke coverage.

   authority;

manifests are not substitutes for those external records.
