## Implemented Boundary

- `/api/experiments/v170-benchmark-candidate-multimodal` returns a typed
  15-slice admission contract and can retain a durable local receipt.
- Candidate admission checks complete/scored item counts, pinned evaluator
  compatibility, exact 500-item pairing, confidence interval, exact McNemar,
  non-inferiority, p95 latency, and runtime failures.
- A repeated run against the same target/model binding is explicitly held,
  even when its run id and score differ.
- MMMU, MathVista, MMBench, and Video-MME v2 protocol conformance remains
  separate from official assets, compatible native image/video transport, and
  retained execution/submission receipts.

3. Install and record the applicable official image/video assets and licenses.
4. Execute every supported official multimodal protocol through a compatible
   native runtime; retain MathVista judge and MMBench submission receipts where
   required.
5. Obtain independent-worker, external-evaluator/submission, and organization
   promotion evidence. These remain separate from local source-gate status.
