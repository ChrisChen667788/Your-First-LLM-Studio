## Delivered Behavior

Actual Ed25519 verification now protects the activation import path. Keys come
from a server-owned public-key policy, with SPKI fingerprints, role/milestone
grants and explicit validity/revocation. Signed envelopes bind issuer, audience,
manifest, nonce, timestamps and body. Observer/verifier pairing requires
independent issuers signing the same domain evidence digest.

Batch import is atomic, revision-protected and retry-safe. Bad signatures
produce digest-only, manifest-scoped quarantine; only the bound authority can
resolve a case. Explicit supersession retires old observations, while revocation
tombstones survive expiry and backup merge. Restore rechecks signatures and
cannot replace newer records. Corrupt primary ledgers fail closed instead of
silently falling back to an older replay ledger.

The Experiments inbox and CLI share the bounded authenticated application API.
The preceding metadata-only promotion bundle now requires the cryptographic
read model for eligibility. Local records cannot grant distribution or
production authority.
