## Implemented

1. Registered MiniMax M3 as an OpenAI-compatible target using `MiniMax-M3`, adaptive thinking, `reasoning_split`, and `max_completion_tokens`.
2. Added an 11-source standards registry covering MMLU-Pro, GPQA Diamond, IFEval, MATH-500, EvalPlus, SWE-bench Verified, LiveBench, MMMU, MathVista, MMBench, and Video-MME v2.
3. Added pinned revision state outside the repository, six-hour automatic refresh, manual refresh, per-source error isolation, Hugging Face HEAD fallback, GitHub Atom fallback, and stale revision retention.
4. Added native image/video task media to the Benchmark plan and official MiniMax message content shapes.
5. Added model-specific official capability evidence. Unknown model ids fail closed; model capability and runtime transport capability are reported separately.
6. Moved all-unsupported local groups ahead of runtime prewarm. Skipped samples have zero latency, no token usage, a reason, and an official documentation URL.
7. All-skip runs now finish as completed-with-skips rather than a crashed process; mixed target batches continue independently.
8. Added a foreground standards registry, modality selector, media URL input, selected-target eligibility preview, and upstream refresh control to `/benchmarks`.
