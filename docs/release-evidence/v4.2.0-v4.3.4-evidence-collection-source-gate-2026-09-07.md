# v4.2.0-v4.3.4 Evidence Collection Source Gate

Date: 2026-09-07

## Decision

All fifteen repository-owned collection mechanisms are source-complete. The ten
feature-owned collectors are now dispatched by `features/evidence` and produce
one sanitized, digest-bound artifact plus a strict candidate receipt only from
a live observation. Reference, fixture, and derived read models fail closed
before submission.

This is a source-completion decision, not a workload or promotion decision.
The current collection projection is `15/15` source pass, `4/15` local pass,
zero queued jobs, zero accepted reviewed jobs, zero external verification,
distribution `HOLD`, and production `BLOCKED`.

## Implemented Scope

- generic domain collection artifact/receipt builder, bound to the prior
  source-milestone metric contract;
- feature-owned Agent, Benchmark, Models, Retrieval, Fine-tune, and Governance
  adapters for the eight previously declarative plans;
- explicit plan dispatch, per-plan artifact stores, lease-fenced candidate
  submission, retry handling, and artifact digest deduplication;
- fail-closed eligibility for non-live observations, missing metrics, invalid
  timestamps, and failing local/source signals;
- Release Train and release-evidence matrix status moved from `planned` to
  `evidence-needed` for `v4.2.6-v4.3.3`;
- source/local/external/production state reflected by the Experiments API,
  smoke contracts, English/Chinese README, and ModelScope README.

## Remaining Evidence

The next work is not more source scaffolding. Each domain collector needs a
fresh, authorized live input and an independently reviewed receipt:

1. Agent lifecycle/protected effects, separate worker recovery, and provider
   cache/billing reconciliation.
2. Licensed multimodal media/evaluator records, model transfer/runtime lineage,
   managed Retrieval corpus and blinded RAG feedback.
3. Non-MLX federated training artifacts, organization-scoped sandbox/team asset
   conflict evidence, verified reviewer identity, retention/read-back, and
   independent promotion sign-off.

No reference fixture, local derived summary, import-only artifact, or review ID
is counted as independent external verification or production authority.
