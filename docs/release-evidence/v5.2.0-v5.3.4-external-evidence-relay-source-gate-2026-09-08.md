## Decision

All fifteen repository-owned external-evidence relay contracts are
source-complete. The train provides a pinned HTTPS relay descriptor, opaque
one-shot credential-resolution contract, bounded digest-only request and
receipt transport, strict response intake, quarantine, freshness and replay
defense, fourteen-domain reconciliation, discrepancy preservation, independent
decision relay, and a non-authorizing production firewall.

distribution, or production decision. The current projection is source `15/15`
pass, deterministic local `9/15` pass, persisted configurations `0`, requests
`0`, receipts `0`, quarantines `0`, reconciliations `0`, covered milestones
`0/14`, external `HOLD`, and production `BLOCKED`.

## Implemented Scope

- `features/evidence/external-relay.ts` owns strict relay configuration,
  endpoint policy, one-shot resolver and transport contracts, request/receipt
  binding, quarantine, fourteen-domain reconciliation, durable-state reducers,
  and default fail-closed execution;
- `features/evidence/external-relay-store.ts` persists bounded, idempotent,
  digest-bound configuration/request/receipt/quarantine state without raw
  credentials or external payloads;
- a feature-owned Experiments API, panel, deterministic export, release-train
  milestones, route-smoke checks, CI route coverage, and documentation expose
  source readiness without providing an unconfigured external action.

## Remaining External Evidence

The following are intentionally not represented as completed by source code:

1. an organization-controlled credential resolver, HTTPS relay authority, and
   pinned trust/rotation observation;
2. immutable archive read-back with verified retention and legal-hold behavior;
3. fourteen current independently issued observer and verification receipts;
4. externally controlled discrepancy resolution and distribution decision; and
5. a separately controlled production transition with an independent execution
   witness and authorization.

An injected test transport, local relay descriptor, accepted-shaped local
receipt, quarantine record, or reconciliation projection cannot replace those
external records or authorize production.
