# v1.3.1 Trust and Durability Hardening

Date: 2026-07-23

This patch responds to the adversarial product audit. It separates repository-closable defects from evidence that can only be produced by external infrastructure or independent operators.

## Closed In This Patch

| Hard issue | Closure |
| --- | --- |
| Conflicting release/version claims | `package.json`, lockfile, `VERSION`, active release train and `release-state.json` now agree on source `v1.3.1`. Public GitHub `v0.4.0` and Desktop candidate `v1.1.0-rc.2` remain explicitly separate. |
| Dependency vulnerabilities | Next/sharp and MCP/Hono production paths were upgraded or pinned. Full and production-only `npm audit` both report zero vulnerabilities on 2026-07-23. |
| No conventional regression tests | Node contract tests now cover atomic persistence, corrupt-store recovery, lock contention, operator authorization, standard completion and SSE behavior. |
| Silent JSON reset and lost updates | All Workflow graph, execution, breakpoint, deployment-key, worker, replay, state-diff, Retrieval and acceptance stores use locked same-directory atomic writes, backups, quarantine and fail-closed recovery. |
| Localhost deployment-key bypass | The deployed Workflow API always requires a version-scoped deployment key. Loopback is no longer an invocation bypass. |
| False OpenAI-compatible response | `/v1/chat/completions` now returns a standard `200 chat.completion` or SSE chunks ending in `[DONE]`. Approval/protected-action boundaries return a durable `409 workflow_requires_resume`; async `202` remains on the dedicated Workflow endpoint. Token usage is labeled estimated. |
| Misleading LoRA public bundle | Public evidence paths are portable, included files are checked for existence, omitted weights/checkpoints are disclosed, and workflow/loss evidence is separated from task-quality promotion. Quality remains `HOLD` without frozen baseline, blind evaluation and multi-seed evidence. |
| Narrow route smoke | CI route smoke now covers every first-line product surface plus representative Workflow, Fine-tune, Model and Extension read contracts. The full local smoke additionally verifies deployment-key denial, standard completion and SSE. |
| Standalone startup mismatch | `npm run start` now launches the generated standalone server, copies required static/public assets, binds loopback by default and preserves an explicit workspace root for source-owned evidence checks. |
| Oversized shells and Agent API routes | Agent, Admin and Fine-tune shells are now at 1,110/1,195/1,194 lines; all three Agent routes are seven-line transport wrappers. `architecture-budgets.json` rejects ownership regression. |
| Mixed legacy mutable JSON durability | Fine-tune repositories, Agent sessions/retrieval/cache/evidence, Model Hub/runtime registries, deployment outbox/settlement, extension lifecycle, governance reviews, runtime conformance and evaluation stores now use shared locked atomic adapters with backup recovery, quarantine and schema validation. `validate:durable-state` rejects unclassified read-modify-write stores. |
