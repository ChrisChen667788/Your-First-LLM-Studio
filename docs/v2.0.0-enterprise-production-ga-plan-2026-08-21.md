# v2.0.0 Enterprise Production GA — implementation plan

Date: 2026-08-21
Status: repository-owned GA reconciliation contract implemented; production authorization remains `BLOCKED`.

## Purpose

`v2.0.0` is not a local release switch. It reconciles the predecessor control-plane
candidate with existing release, desktop, identity/data-plane, and security evidence,
while explicitly separating source validation from independently controlled production
acceptance.

## Delivered repository-owned slice

- `features/experiments/enterprise-production-ga.ts` exposes a deterministic read
  model and durable local reconciliation receipt.
- `/api/experiments/enterprise-production-ga` supports read-only evidence retrieval
  and an operator-protected snapshot capture.
- `/experiments` shows local, external, and production states separately; the UI
  labels the production result `BLOCKED` rather than treating a local check as GA.
- A test uses an all-passing fixture and still requires `externalStatus: hold` and
  `productionStatus: blocked`.
- Route smoke and an evidence-export command cover the API contract. The command
  fails if a local run ever returns a production-ready result.

## Required external acceptance packet

The following receipts remain outside repository authority and must be independently
verified by the release authority:

1. Managed OIDC/SCIM, PostgreSQL RLS, vector retrieval, telemetry, KMS/Object Lock,
   and durable-worker evidence in the target environment.
2. Cross-region failover rehearsal against declared SLO, RPO, and RTO, with immutable
   audit/archive records.
3. Billing-settlement acknowledgement and quota/retention policy evidence from the
   accountable service owners.
4. Independent security assessment, signed distribution/clean-machine acceptance,
   and organization/operator sign-off.

No local smoke, fixture, preview, generated receipt, or source-only panel is eligible
to promote this version. The release authority must validate imported external
artifacts and own the final production transition.
