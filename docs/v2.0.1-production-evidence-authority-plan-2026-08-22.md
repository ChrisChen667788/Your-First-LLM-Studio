# v2.0.1 Production Evidence Authority — implementation plan

Date: 2026-08-22
Status: source-owned verification contract implemented; production authorization remains external.

## Objective

`v2.0.1` makes the boundary after `v2.0.0` actionable without pretending that a
local application can issue, import by UI action, or approve production evidence. It
verifies an independently supplied, detached-signature evidence bundle against a
pinned public-key digest and a fixed receipt inventory.

## Delivered repository-owned slice

- The verifier reads bundle, signature, public key, and pinned public-key SHA-256
  only from `FIRST_LLM_PRODUCTION_EVIDENCE_*` configuration paths.
- The bundle must bind v2.0.0, source revision, artifact digest, durable issuer,
  independent review, fresh receipts, and nine required production receipt types.
- At least two external attestor organizations are required. Local/test/fixture
  identities, invalid signatures, missing trust anchors, stale receipts, and partial
  inventories fail closed.
- The endpoint is read-only. It creates no receipt and exposes no raw evidence bytes
  or configured filesystem paths.
- The verifier exposes only the bundle SHA-256 and evidence-issuer organization needed
  for a subsequent independent decision to bind the exact reviewed bundle; it exposes
  neither raw evidence bytes nor configured filesystem paths.
- A complete signed-fixture unit test may reach `evidenceStatus: verified`, but
  `authorizationStatus` remains `not-authorized` and `productionStatus` remains
  `blocked`.

## External release authority inputs

The independent release authority is responsible for generating and safeguarding the
bundle and detached signature. It must include identity, data, telemetry, KMS/archive,
failover, billing, security, distribution, and organization receipts. The actual
authority transition and deployment promotion are explicitly outside this repository.
